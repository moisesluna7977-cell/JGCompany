# J&G COMPANY — Android

Proyecto Android listo para abrir en Android Studio. La app envuelve la versión funcional web/PWA en un WebView para producir una app Android instalable.

## Generar APK
1. Abrir esta carpeta en Android Studio.
2. Esperar a que Gradle sincronice.
3. Ejecutar **Build > Build APK(s)**.
4. El APK de debug quedará en `app/build/outputs/apk/debug/app-debug.apk`.

Requisitos: Android Studio reciente, Android SDK 35 y JDK 17.
